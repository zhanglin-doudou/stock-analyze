### 第一类：会让数字方向错误的（R-A1 ~ R-A10）

#### R-A1 期初资产从未定义 + 首行非买入即丢数据 —— 所有收益率的分母缺失
- **位置**：§5.1 第 83 行；FR-R2 第 140 行；[F-A1] + [I-A3]
- **问题**：`TWR` 的 `r_t = (V_t − V_{t−1} − CF_t) / V_{t−1}` 隐含 `V_{t−1}` 完整且含现金，但全文未定义"期初资产/期初资金余额"。同时第 83 行规定首行非买入则**不存储该行**，导致现金链起点缺失、FR-L5 余额链必然断裂，净值退化为"持仓市值曲线"——空仓期不可见、现金收益被剔除。
- **投资者侧同一处**：华泰通常只能导出近 1~2 年账单，用户永远导不出"从第一支股票开始"的完整流水，规则一卡 100% 导入失败，且只说"不存储"不说为什么。
- **修改方向**：
  - 删除第 83 行丢弃逻辑，改为「首行无论买卖均完整入库」；
  - 新增 `period_initial_cash = 首行资金余额 − 首行发生金额`，标 `assumption=back_solved`；
  - 日终资产 = 证券市值（收盘价，停牌用前收盘标 `stale`）+ 资金余额（按最近发生行前值填充）；
  - 反推失败则该区间净值标 `NAV_UNRELIABLE`，仅输出回合级指标，不输出年化/夏普/回撤/超额收益；
  - 前端提示人话：「你的账单从 2023-01-03「利息归本」开始，净值起点为 2023-01-03，此前收益不计入。[继续][看示例]」

#### R-A2 外部现金流边界未定义 + 只有 TWR 没有 MWR
- **位置**：FR-R2 第 140 行；附录缺"外部现金流"条目；[F-A2]
- **问题**：示例账单已含「利息归本」（92 行）、「股息入帐」（93 行）。股息/利息若当外部现金流折份额 → 低估收益；银证转账若当内部收益 → 高估收益。且全文只有 TWR。
- **依据**：TWR 只剔除投资者可控外部现金流，公司行为属收益；个人投资者真实体感是 MWR（"我赚了多少"），策略质量是 TWR，二者之差恰是资金进出的择时效应，本身就是洞察。
- **修改方向**：附录新增「外部现金流仅含银证转账（转入正/转出负）、配股缴款、场内基金申赎款；股息、红利税、送转、利息归本、佣金税费、融资利息一律内部收益，不折份额；CF 记为日末发生，按当日日末单位净值折份额」。新增 FR：同时输出 TWR 与 MWR（XIRR，ACT/365）及 `MWR − TWR` 与解释（>0 表示资金更多投在盈利期）。

#### R-A3 基准与超额收益未定义（"跑赢了吗"不可信）
- **位置**：§1.3 第 25、30 行；FR-R4 第 152 行；[F-A3] + [I-B4]
- **问题**：第 25 行「净值曲线 vs 上证/创业板/科创板」未指定代码、全收益 vs 价格指数、对齐频率、归一化起点；同一组合同时给 3 个指数等于没有基准。第 30 行「买入后超额收益率(与指数收益进行对比)」同样无定义。
- **依据**：上证指数为价格指数，股息率约 2%，5 年累计低估基准约 10pp。未做 β 调整的"组合减指数"把市场暴露误记为选股能力——高 β 组合牛市必"跑赢"、熊市必"跑输"。
- **投资者侧**：基准选错更贴近体感——2024 年"跑赢上证 3 个点"但账户亏钱，属于自我安慰；圈层真正对标的是沪深300 和自己的基金/定投。
- **修改方向**：
  - 默认基准 = **沪深300 全收益**；区间日收益 OLS 估 β，β 偏离 1 超 ±0.2 时追加中证500/1000/创业板指全收益；
  - 基准比较须同起点归一为 1.0、同一交易日历、全收益；仅价格指数时单列股息贡献并标 `benchmark=price`；
  - 超额同时输出算术日超额 `Σ(r_p−r_b)` 与几何累积超额 `Π(1+r_p)/Π(1+r_b)−1`；
  - 另输出 β、年化 Jensen α 及 t 值、跟踪误差、IR；
  - 展示层**绝对收益排第一**，超额排第二，且必须带 `benchmark_id + β` 标注。

#### R-A4 归因缺失——四问拼不出"我为什么亏"（**从 P1 提级为 Blocker**）
- **位置**：§1.2 第 17–21 行（只有选股/择时/行为三分）；FR-R3/R4 仅算描述性指标；[F-B2 提级] + [I-B1] + [I-§6]
- **问题**：没有任何一条 FR 回答"我的亏损来自哪里"。选股能力仅靠"买入后超额收益 + akshare 财务字段"，无法剥离配置与选择；未拆行业/板块/买点/卖点/费用/情绪各贡献多少。
- **依据**：不拆配置与选择时，"选股能力差"可能实际是"行业押错"，改进动作完全不同。归因是复盘的产品灵魂，不是加分项。
- **投资者侧**：「四问是体检报告，不是医嘱。读完知道胜率 43%、盈亏比 1.2，然后呢？」且"提升建议"只在第 30 行定位句出现一次，**全篇没有一个 FR 是"给建议"**。
- **修改方向**（M1 出简化版，M2 出完整版）：
  - **P0 简化归因（M1）**：亏损金额拆五因子——选股（相对行业）/ 板块 / 买点（追高程度）/ 卖点（卖飞）/ 费用，各项金额与占比，输出"你的钱亏在 O 项，不是 N 项"一句结论；
  - **P1 完整归因（M2）**：申万一级 Brinson-Fachler（配置/选择/交互），多期用 Carino 链接；行业偏离 `Σabs(w_p−w_b)/2`；
  - **P0 行动建议（M1）**：每个核心指标强制配"一句人话解读 + 一条动作"，**且只给一条**（人一次只能改一个习惯）。

#### R-A5 前视偏差未约束——"选股能力"会被系统性高估
- **位置**：FR-R3 第 143–148 行；FR-R4 第 153 行；§9 第 209 行；[F-A4]
- **问题**：FR-R3 只要求"调用 akshare 接口计算"，未规定财务数据的 point-in-time（公告日 as-of）。用"最新财报"评价历史买入即前视偏差；季报年报存在披露滞后与追溯调整。FR-R4 的卖出后 5/10/20 日窗口在"最近一周"区间内常未走完，未定义 pending。
- **依据**：归因第一原则是只用决策时点可获得信息。偏差方向恒为正，加样本不能消除。
- **修改方向**：新增 NFR「时点一致」：所有基本面/行情按 `announce_date ≤ 决策日` 过滤；akshare 无公告日时以法定披露截止日（年报次年 4/30、季报次月/次季末）为保守可用日；区间诊断输入数据截止日不晚于 `as_of`，meta 记录 `data_as_of` 与 `factor_version`；窗口未走完的回合标 `pending_window`，不计入卖飞率分母。

#### R-A6 公司行为未进回合 pnl + 打新分类缺失
- **位置**：FR-L4 第 118 行；FR-R2 第 139 行；附录第 224 行；[F-A5] + [I-A4 打新部分]
- **问题**：① 分红/送转判为"公司行为流"后与回合脱钩，回合 pnl 只做 FIFO 买卖配对，持有期股息（约 2%/年）与红利税未计入，长期回合 pnl 系统性低估；② 送转/配股改变数量与成本，未定义 FIFO 成本调整规则；③ 打新（申购中签/新股缴款）常无证券代码、只有发生金额，归不进交易流，净值算错。
- **修改方向**：
  - 回合 pnl = `Σ卖出发生金额 − Σ对应买入发生金额绝对值 + 该回合持股数对应股息净额（税后）`；
  - 股息按 FIFO 持股数在除息日归属；送转按公告比例放大数量、总成本不变；配股缴款计入买入成本；
  - 跨除权日回合过一致性单测：调整后「买入成本 + 股息 − 卖出净额」与账单现金流差额 = 0（容差 0.01 元）；
  - 摘要规则表新增「打新/新股缴款」类型，作为**独立资金占用流**，不参与回合配对但计入净值与现金。

#### R-A7 盈亏集中度无定义 + 已平仓胜率的截断偏差
- **位置**：§1.3 第 26 行（引用"盈亏集中度"）vs 附录 213–225 行（**无该词条**）；附录 217 行；[F-A6]
- **问题**：MVP 第 2 问要求的"盈亏集中度"在附录没有定义，实现方可自由发挥（"Top1 盈利占比"或"pnl HHI"量级完全不同）。胜率只统计已平仓回合，而用户"卖盈留亏"正是处置效应，导致胜率被系统性高估。
- **修改方向**：附录补三条——① 集中度（主）= Top3 盈利回合盈利之和 / 全部盈利回合盈利之和；辅助 CR1 与 Gini；分母仅含 pnl>0；② 胜率须并列"全样本胜率"= (已实现盈利 + 期末浮盈) / (已平仓 + 未平仓)，浮盈按期末价与摊薄成本计；③ 所有比率同附 N 与 Wilson 95% CI。

#### R-A8 卖飞率阈值失效 + 追涨分位用不复权价
- **位置**：附录 220 行（卖飞率）、221 行（追涨分位）；[F-A7]
- **问题**：① 卖飞阈值"20 日基准调整涨幅 > 5%"是固定绝对数，日波动 2.5% 的个股 20 日 σ≈11.2%，5% 仅 0.45σ，随机游走下也有约 1/3 概率触发，指标失去区分度；②"基准调整"未定义是减指数还是 β 调整；③ 多笔部分卖出未定义加权；④ 追涨分位明确"不复权价"，窗口内除权会凭空造极值；⑤ 未定义窗口是否含买入当日。
- **修改方向**：卖飞率改为按波动率标准化的 z 分数：`z = (R_after − R_bench,h) / (σ_i日·√h) > 1.0`，`h∈{5,10,20}`，按卖出金额加权，`σ_i日` 取卖出日前 60 日日收益标准差，`R_bench,h` 为 β 调整基准收益（β 取前 250 日 OLS），5% 仅作辅助展示不作判定；追涨分位改用与买入日价格水平对齐的**复权序列**，窗口 `T−20..T−1`（不含 T），高低相等返回 NULL，并列 z 版。

#### R-A9 费用二次扣费风险 + "费用占比"分母缺失
- **位置**：附录 217–218 行（"含费"）；FR-R4 第 152 行；[F-A8]
- **问题**：① "其他费"未定义是否含过户费/经手费/证管费，口径不闭合；② "发生金额"买入已含费、卖出已扣费，若 FIFO 用发生金额再"含费"叠加佣金即**二次扣费**；③ "费用占比"分母完全未定义（成交额/期初资产/平均资产相差一个数量级）——直接导致 MVP 第 3 问不可回答。
- **修改方向**：附录补——费用合计 = 佣金 + 印花税 + 其他费（其他费在数据字典展开为过户费/经手费/证管费/结算费）；回合 pnl 已由发生金额内含费用，**禁止二次扣费**；费用占比（主）= 区间费用 / 区间双边成交额；辅助 = 区间费用 / 平均总资产（年化 bp）、区间费用 / 区间 TWR 收益；另输出"费用回本门槛" = 年化费用 / 年化平均持仓市值。

#### R-A10 验收标准不可判定（G2「数据可信」不可证）
- **位置**：G1 第 38 行；FR-L5 第 122 行；FR-R3 第 146 行；§8 M1 第 196 行；[F-A9]
- **问题**：「与手工抽查（≥10 回合）一致」「上一行余额 ± 发生金额 ≈ 本行余额」均无容差、无抽样规则；FR-R3 验收是"接口调用成功"——**只验活不验对**，任何错误指标都能通过验收。
- **修改方向**：
  - 回合：分层抽样 30 回合（加仓/分批减/同日多笔/分红/送转/超卖各 ≥3），逐笔核对 pnl 差额 ≤ 0.01 元、回合收益率差额 ≤ 1bp、FIFO 买卖 `trade_id` 集合 100% 一致；
  - 净值：日收益 diff ≤ 1bp、区间累计收益 diff ≤ 5bp；
  - 对账：断链检出率 100%，余额链阈值 0.01 元；
  - 指标：固定 fixture（合成流水 + 固定行情快照）跑 golden test，与预期 diff = 0，同输入重复计算 diff = 0。

### 第二类：会让产品不可用的（R-A11 ~ R-A13）

#### R-A11 交付形态：零可视化 + 部署门槛（**投资者视角唯一致命级，金融视角部分认同**）
- **位置**：§4 第 70 行「五大能力全部 API 化（无可视化）」；§7 第 183 行 Non-goals；§4 第 72 行「PostgreSQL 同实例分库」；NFR-5 第 175 行「uv workspace Monorepo」；[I-A1] + [I-A2]
- **问题**：对话问答是 P1 且是"最终形态"，所以 M0–M1 整段用户界面为 0，个人用户拿到的是 `localhost:8000/docs`。同时"装 PostgreSQL + uv workspace"对目标用户即乱码，中间任何一步失败就永久卡死。**一个 0 界面的付费产品对个人用户等于没交付。**
- **修改方向（含 §3 中 R-C1/R-C6 裁决）**：
  - 默认部署改为 **SQLite 单文件**（`~/Documents/交易复盘/ledger.db`）+ 一键启动（双击 `.command` / `docker compose up`）；PostgreSQL 保留为"未来云端多用户可选部署"，不作为个人用户默认路径；
  - **P0 新增只读单页 UI**：一个 HTML 模板渲染 5 张卡片（分段净值 vs 基准、胜率/盈亏比/持仓天数/集中度、手续费、处置效应、最亏最赚 3 笔），点击可下钻到流水；不做前端工程化、不做前后端分离；
  - §7 Non-goals 中"可视化前端"改为「不做重前端工程化（路由/状态管理/组件库），只做服务端渲染只读页」；
  - 但采纳金融视角门禁：**卡片数字必须先过 R-A10 的 golden test，未过则显示"口径修复中"，不得渲染可能误导的超额收益结论**。

#### R-A12 导入鲁棒性：列映射/日期格式/资金余额列/无可撤销批次
- **位置**：§5.1 第 83 行；FR-L2 第 103 行（13 个固定字段）；示例第 89–93 行（日期 `20230103`）；FR-L5 第 121–123 行；§5.1 第 109 行「无批次表」；[I-A4] + [I-B8 ①]
- **问题**：① 华泰真实对账单前面有 3~4 行标题（客户姓名/资金账号/对账期间），列名为「成交日期」「成交数量」而 PRD 叫「日期」；日期格式为 `2023/1/3` 或 Excel 日期型，PRD 是 `20230103`；② **交割单没有「资金余额」列，而 FR-L5 对账全靠它**——用户导错了系统不提醒；③ 没有批次表 → 用户想"把上次导的那份撤了重导"做不到，个人用户最需要的是后悔药。
- **修改方向**：① 导入向导：自动识别表头 + 用户点两下做列映射并记住；② 日期多格式识别（`20230103`/`2023-01-03`/`2023/1/3`/Excel 序列号）；③ 文件自检：无资金余额列时明确提示「你导的可能是交割单，对账将不可用」并降级；④ 提供 Excel 模板；⑤ **恢复批次表**：`import_batch`（时间/行数/隔离区行数/可撤销），支持一键撤销上次导入。

#### R-A13 隐私闸门与 G3 自相矛盾 + 无备份/迁移方案
- **位置**：FR-R5 第 162 行「隐私闸门：LLM 出站剥离资金绝对值与账号（只传比例/分位）」vs G3 第 40 行「我本月为什么亏」；NFR-1 第 171 行；NFR-3 第 173 行；[I-A5] + [I-B8 ②]
- **问题**：① 用户最常问的就是"我这个月赚了多少"，而 AI 看不见金额，只能回"根据比例…"，用户会判定产品在糊弄；且"看得到持仓、看不到钱"自相矛盾；② 全篇无备份/导出/迁移方案——**"我笔记本进水了，8 年账单和历史复盘是不是就没了？"** 这是用户敢不敢交真数据的前提。
- **修改方向**：① 隐私改为**用户可见开关**，默认允许 AI 读取本地金额（数据不出本机）；真脱敏发生在**远程 LLM 出站那一刻**，并单独标注"当前回答由本地模型/已脱敏"；② P0 新增「数据主权」需求：一键导出全量（Excel + JSON）、每周自动备份到指定目录、导入导出可迁移；③ **需要澄清 G3 口径**：如果坚持出站脱敏，则 G3 必须改写为"回答中金额由本地计算填充、LLM 只负责组织语言"（推荐此方案，既保隐私又保体验）。

## 5. 指标口径修订表（合并双方，可直接替换 PRD 附录）

| 指标 | PRD 现口径 | **修订后口径** | 来源 |
|---|---|---|---|
| 期初资产 | **无** | `period_initial_cash = 首行资金余额 − 首行发生金额`，标 `assumption=back_solved`；失败则 `NAV_UNRELIABLE` | F-A1 |
| 净值/TWR | 「份额法处理出入金，不扭曲收益率」 | `NAV_u,t = (Σ证券市值_t + 资金余额_t) / 份额_t`；`份额_t = 份额_{t−1} + CF_t / NAV_u,t`；`r_t = NAV_u,t / NAV_{u,t−1} − 1`；`TWR = Π(1+r_t) − 1`；年化 `(1+TWR)^(365/自然日) − 1`；普通账户不含负债 | F-A2 |
| MWR | **无** | XIRR：`Σ CF_i/(1+x)^((d_i−d_0)/365) = 0`，CF 含期初投入（负）与期末市值（正）；同时输出 `MWR − TWR`（>0 = 资金在盈利期投入更多） | F-A2 |
| 外部现金流 | **无** | 仅含银证转账、配股缴款、场内基金申赎款；股息、红利税、送转、利息归本、佣金税费、融资利息一律内部收益；CF 记日末发生 | F-A2 |
| 回合 pnl | 「FIFO 配对」 | `pnl = Σ卖出发生金额 − Σ对应买入发生金额绝对值 + 该股数对应股息净额`；收益率 `= pnl / Σ买入成本（含费）`；送转按比例放大数量、总成本不变；配股缴款计入买入成本 | F-A5 |
| 胜率 | 「已平仓回合 pnl>0 占比（含费）」 | 已平仓胜率 + **并列全样本胜率** `= (已实现盈利 + 期末浮盈)/(已平仓 + 未平仓)`；附 N 与 Wilson 95% CI | F-A6 |
| 盈亏比 | 「平均盈利 ÷ 平均亏损绝对值」 | 金额口径 `平均盈利金额 / abs(平均亏损金额)`，并列 median 版；同出期望值 `E = p·W − (1−p)·L` 与盈亏平衡胜率 `p* = 1/(1+盈亏比)` | F-A6 |
| 平均持仓天数 | 隐含 | 交易日计：卖出日 − FIFO 对应买入日（同日记 1）；并列 median、自然日版、资金占用天数（摊薄加权） | F-A6 |
| **盈亏集中度** | **无定义**（第 26 行引用） | 主：`Top3 盈利回合盈利 / 全部盈利回合盈利`；辅：CR1、Gini；分母仅含 pnl>0 | F-A6 |
| 处置效应 | 「亏损回合均持 − 盈利回合均持」 | **主：Odean 口径 `DE = PLR − PGR`**，`PGR = 已实现盈利笔数/(已实现盈利+期末浮盈笔数)`，`PLR` 同理；附 bootstrap 95% CI，`DE>0` 为处置效应；持有天数差降为辅助并注明 FIFO 口径与 N | F-B8 |
| 卖飞率 | 「20 日基准调整涨幅 >5%」 | `z = (R_after − R_bench,h)/(σ_i日·√h) > 1.0`，`h∈{5,10,20}`，按卖出金额加权；`σ_i日` 取卖出日前 60 日；`R_bench,h` 为 β 调整（前 250 日 OLS）；停牌>50%/退市/未走完剔除并计 pending | F-A7 |
| 追涨分位 | 「(买入价 − 近20日最低)/(近20日最高 − 近20日最低)，不复权价」 | 用与买入日价格水平对齐的**复权序列**；窗口 `T−20..T−1`（不含 T）；高低相等返回 NULL；并列 `z = (P_buy − mean20)/σ20`；meta 标 `freq=daily` | F-A7 |
| 最大回撤 | 「峰值到后续谷值最大跌幅」 | `MDD = min_t(NAV_t / max_{s≤t}NAV_s − 1)`，**必须同时附**：持续期、恢复期、水下时间占比、`Ulcer = √mean(DD_t²)`、`Calmar = 年化收益/abs(MDD)` | F-B3 |
| 仓位 HHI | 「Σ(单票市值/总市值)²，每日」 | 双口径：`HHI_eq = Σ(市值_i/Σ市值)²` 与 `HHI_total = Σw_i²`（含现金为一项）；区间给逐日均值 + 最大值 + 期末值 | F-B3 |
| 夏普 | 「夏普值」 | `(r̄_d − rf_d)/σ_d × √A`；`rf` 参数化默认 1 年期国债/货基 7 日年化（**禁止默认 0**），`A=244`；附 t 值与 Lo(2002) 自相关调整 | F-B4 |
| **费用占比** | **无分母** | 主：`区间费用 / 区间双边成交额`；辅：`/ 平均总资产（年化 bp）`、`/ 区间 TWR 收益`；另出"费用回本门槛"；费用合计 = 佣金+印花税+其他费，**禁止二次扣费** | F-A8 |
| 基准超额 | 「与指数收益进行对比」 | 全收益指数、同起点归一、同一交易日历；算术日超额与几何累积超额并列；附 β、年化 α 及 t、跟踪误差、IR；默认沪深300全收益 | F-A3 |
| 区间诊断门槛 | 「最近一周/月/季度/年度」 | 日频 <60 交易日**不输出**夏普/回撤/IR；回合 N<30 全部比率附 CI；N<10 只出原始值不出结论 | F-B1 |
