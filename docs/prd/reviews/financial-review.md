# 金融专业视角评审：个人交易复盘体系 PRD v1.0

> 评审对象：`docs/PRD.md`（225 行，v1.0，2026-10-18）。评审视角：券商研究所量化研究 + 买方基金组合经理。口径参照 TWR/MWR 体系、Brinson 归因与 Odean 行为金融实证。

## 0. 评审结论

- **总体结论：需重大修改**。数据底座（余额链对账、软删可追溯、行级幂等、指标血缘）在个人项目中属上乘；但"度量层"仍是四则运算级，存在四类会让结论方向错误的结构性缺陷：**收益率分母（期初资产）缺失**（line 83/140）、**外部现金流边界未定义**（line 140）、**基准未定义**（line 25/152）、**前视偏差未约束**（FR-R3/R4）。这四条不修，MVP 四问每个数字都"看起来正确、实际不可信"。
- **总体评分：4.0/10**
  - 指标严谨性 4.0 ｜ 计算正确性 4.5 ｜ 归因深度 3.0 ｜ 数据可行性 5.0 ｜ 验收可测性 3.5
- **一句话判断**：这份 PRD 把"数据不会错"做到 8 分，把"数字不会骗人"只做到 3 分——对账只能证明流水没错。

## 3. 可选优化（P2）/ 长线议题

## 4. 对「MVP 四问」的专业判断

**第 1 问（净值 vs 指数）：能答，但当前口径会给出错误结论。** 缺基准规则、全收益、β/α 分离、起点归一、期初资产与显著性。未修 F-A1/A3 前，答案本质是"高 β 组合牛市必然跑赢"的伪结论。建议固定三行结构：`TWR 累计 x%（几何）｜同期基准全收益 y%｜β 调整 α = z%（t=…, 样本 n 日）`。

**第 2 问（四数字定性风格）：四问中最不可靠的一问。** 缺盈亏集中度定义（F-A6）、N/CI（F-B1）、含浮盈亏口径、持仓天数单位与盈亏平衡胜率。几十个回合下四数字 CI 可宽达 ±18pp，不应以"你的风格是 XX"断言式输出，应分级表述"样本能支持 / 不能支持"。

**第 3 问（手续费占比）：可答，缺分母与参照系。** 补 F-A8 的分母、其他费展开、年化费率 bp，末句固定"费用拖累 = 年化 X bp，相当于吃掉 TWR 的 Y%"，才真正回答第 3 问。

**第 4 问（处置效应）：代理指标不专业。** 建议直接换 PGR/PLR（F-B8），保留持有天数差为辅助；否则该结论与行为金融文献不可比，也无法与胜率交叉验证——两者共用同一处置效应偏差，会自我印证。

## 6. 与 reviewer 观点的潜在冲突预警

同期 `review-investor.md` 同样给 4/10，但它扣"交付形态"、我扣"口径正确性"。以下 5 处需 lead 裁决：

1. **界面 vs 口径谁先**：对方要 M0/M1 先出"5 张卡片 + 一页纸"并砍变更流/区间替换。我同意交付物是卡片而非 API，但反对在 F-A1/A2/A3 修好前渲染——错误口径配漂亮界面，用户会把"跑赢上证 3 个点"当真并加仓，比没有界面更有害。建议并行开发，卡片数字须先过 golden test（F-A9④），未过则显示"口径修复中"。
2. **基准可选 vs 默认锚定**：可选是对的，但无默认锚定与 benchmark_id/β 标注，用户会长期切到自己跑赢的指数（基准套利）。建议默认沪深300全收益，可切换但超额数字强制带 benchmark_id 与 β，切换前后历史不入同一趋势线。
3. **"砍 JSON" vs 结构化 meta**：`definition_version/assumptions/n/ci` 是 G2/G3 的前提，不能砍。做双层：DB/API 保结构化，渲染层出人话 + 一行"这数我信不信（N 回合，区间 x–y）"，兼得其 I-B2 与 F-B1。
4. **对账 FAIL 硬阻断 vs 分级**：其 I-B7 要求 FAIL 即全区间阻断；我主张净值/回撤/超额硬阻断、回合级指标在断链区间外仍输出并标"含 N 笔可疑"，否则"错一笔、整月不可用"会逼用户绕过系统。
5. **"砍区间替换" vs 可修复性**：区间替换是修错账与送转补录的唯一手段（F-A5 依赖），建议降级为"修复模式"（UI 隐藏、API 保留），不做日常路径。
6. **共识项**：line 83 必须删（其 I-A3 与 F-A1 一致，且示例 line 92 首行即「利息归本」，自相矛盾）；"四问拼不出为什么亏"（其 §6 末段）即 F-B2。若采纳其"每月一条行动建议"，文案须限定为复盘/教育口径，避免构成投资建议（合规）。
