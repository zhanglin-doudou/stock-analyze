# 个人投资者视角评审：个人交易复盘体系 PRD v1.0

## 0. 一句话结论

- **结论：要满足 4 个条件才会用**——①打开就能看见东西，不是一个 API 地址；②不装 PostgreSQL、不敲命令行；③导入失败要用人话告诉我为什么、怎么补；④每月给我一页能看懂、能截图的复盘报告，加一条下月行动建议。
- **评分：4/10**（"把流水拆成选股/择时/行为"这个洞察值 8 分；交付形态 1 分；需求取舍 3 分。这份文档更像给开发看的架构附录，不是产品需求文档。）
- **最刺痛我的一句话**：第 183 行 Non-goals——「**❌ 可视化前端（本期不做；metric_results 的 table 数据已为未来渲染预留）**」。你连"给我看结果那一页"都要预留给未来，那我 M0/M1 到底在用什么？我是付费用户，不是你的 QA。

## 1. 致命问题（会让我直接放弃）

### I-A1 位置：第 70 行「五大能力全部 API 化（无可视化）」、第 183 行 Non-goals

**我不会用。** 我不开 Postman，没写过 SQL，"接口"这词都是刷雪球看到的。你说 M0/M1 验收是"MVP 四问 API 可答，且与手工抽查一致"——我拿到手的是一个 `localhost:8000/docs` 页面，一排英文和 "Try it out"，我该点哪个？返回 `{"win_rate":0.43,"pnl_ratio":1.2}`，然后我自己在脑子里画图？

为什么致命：G3 那个"对话"是 P1、还是"最终形态"（第 157 行）。所以 M0 到 M1 整段，用户界面是 0。一个 0 界面的付费产品，对个人用户等于没交付。

怎么改：最小可视化成本低到不值得省——不要前端框架，一个 HTML 模板渲染 5 张卡片（净值 vs 基准、胜率/盈亏比/持仓天数/集中度、手续费、处置效应、最亏最赚 3 笔），浏览器直接打开。这是 **P0 里的 P0**，排在变更流前面一百倍。

### I-A2 位置：第 72 行「PostgreSQL 同实例分库」、第 175 行「uv workspace Monorepo」

**"装 PostgreSQL"五个字就把我劝退了。** 我上次听到这个词是同事装数据库搞了一下午。我知道 Mac 上有 python，但不知道 3.11 和 3.12 的区别，`uv workspace`、`锁文件`、`Monorepo` 对我来说就是乱码。我买它是为了复盘股票，不是为了在这台 MacBook 上搭微服务。中间任何一步失败，我就永远卡在第一步，且不知道该搜什么。

怎么改：**SQLite 单文件**，放 `~/Documents/交易复盘/ledger.db`；双击 `.command` 或 `docker compose up` 一条命令起来。给个人用户装数据库服务器，是拿服务器思维做桌面软件。

### I-A3 位置：第 83 行「起始账单数据必须为第一支股票买入，否则不存储该账单数据」

**这条会让我导入失败，而且我永远不知道为什么。** 我的账单第一行是"银证转账"或"利息归本"——你文档自己的示例第 92 行第一行就是「利息归本」，你的示例就违反了你自己的规则。我 2015 年买的第一支是中信证券，但华泰只能导出最近 1~2 年，我永远导不出"从第一支股票开始"的完整账单。规则一卡，我 100% 导不进去，而你只说"不存储"，不说为什么。

怎么改：删掉。用资金余额链自推起点；真校验，报错要人话：「你第 1 行是「利息归本」，不是股票买入，净值起点会不准，但仍可导入，收益从第一笔买入 20230103 起算。继续吗？[继续][看示例]」。

### I-A4 位置：第 103 行「13 个固定字段」、第 89–93 行示例（日期 `20230103`）、第 84 行格式支持

**华泰导出来的东西和这 13 个字段长得不一样。** 我导的对账单前面还有三四行标题（客户姓名、资金账号、对账期间），列名是「成交日期」「成交数量」，你叫「日期」；日期是 `2023/1/3` 或 Excel 日期型，你是 `20230103`。改代码我改不了，只能改 Excel，13 列改错一列就错位。更坑：**交割单没有「资金余额」列**，而 FR-L5 对账全靠它，我导错了你不会提醒。另外 FR-L4（第 118 行）分类漏了**打新**——「申购中签/新股缴款」常没证券代码、只有发生金额，归不进交易流，净值就算错。

怎么改：①导入向导，让我点两下做列映射并记住；②日期多格式识别（`20230103`/`2023-01-03`/`2023/1/3`/Excel 序列号）；③文件自检：没资金余额列就提示"你导的可能是交割单，对账将不可用"；④给个 Excel 模板。

### I-A5 位置：第 162 行「隐私闸门：LLM 出站剥离资金绝对值与账号（只传比例/分位）」

**我花这钱，第一句问的就是"我这个月赚了多少"。** 你告诉我 AI 看不见金额——那我问"我本月为什么亏"，AI 回"根据比例，你的亏损主要来自…"，我当场就不信这产品了，甚至觉得你在糊弄我。我也理解不了"你看得到我的持仓、却看不到我的钱"。

怎么改：做成我能看懂的开关，默认允许：「☑ 允许 AI 看到我的持仓金额（只在本机，不上传）」。真要脱敏就发生在日志外发那一刻，别让 AI 变瞎子。这条还和 G3（第 40 行"我本月为什么亏"）自相矛盾，你自己先想清楚要回答什么。

## 2. 强烈不满 / 体验硬伤（P1）

### I-B1 位置：第 23–28 行「MVP 四问」
**四问是体检报告，不是医嘱。** 我读完知道胜率 43%、盈亏比 1.2、持仓 9 天、处置效应 8 天、手续费占亏损 12%。然后呢？"提升建议"只在第 30 行定位句里出现一次，**全篇没有一个 FR 是"给建议"**。
改：每个指标后强制一句人话解读 + 一条动作，**且只给一条**（人一次只能改一个习惯）。例："你亏钱时拿 14 天、赚钱时拿 6 天，你在砍利润留亏损。下月只做一件事：浮亏超 8% 时先问『我当初买它的理由还成立吗』。"

### I-B2 位置：第 39 行 G2、第 163 行验收「每个数字可追溯来源」；第 128/139/183 行术语
"追溯""血缘""metric_id""水位线""隔离区""FIFO 回合"——**这些词我不认识也不想认识**，全文档没有一句用户界面文案。我只想知道：这数我信不信。你甩一个 `metric_id=8821, computed_at=…` 我只会觉得你在甩锅。
改：每条结论固定三行——**结论（人话）→ 怎么算的（一句话）→ 涉及哪几笔（可点开看流水）**。够了。

### I-B3 位置：第 157 行 FR-R5「对话复盘问答——P1（产品最终形态）」+ 第 207 行幻觉应对
对话是**最终形态**却**风险最高**，还放在唯一能串起全产品的位置。AI 说错一个数，我不会当 bug，我会觉得这产品是骗人的——我是拿它做投资决策的。第 207 行"工具强制取数 + 引用 metric_id + 低温度"工程上对，但**我这边零感知**。
改：①对话只做"查数 + 解释"，不做预测推荐（顺便躲开投顾合规）；②给 10 个固定问题按钮，我点就行，不用会打字；③每个回答底部一行"来自你 3–10 月 137 笔已平仓，[看流水]"。

### I-B4 位置：第 25 行「净值曲线 vs 上证/创业板/科创板」
**基准选错了。** 我 2024 年"跑赢上证 3 个点"但账户亏钱；同事买纳指 ETF 赚 20%；老婆的基金赚 8%。你说我跑赢了，我只觉得你在安慰我。熊市里跑赢上证是"少亏"，不是本事。
改：基准可选沪深300/中证500/中证1000/上证/创业板；"**绝对收益**"排第一；加"我的收益 vs 我的定投/我的基金"，让我填一个对数就行。

### I-B5 位置：第 28 行处置效应、附录第 219 行
**你只负责检测，不负责叫醒我。** 算出"我亏钱时多拿 8 天"，我点头，下月继续死扛。我要的不是事后一个数字，是**下次手指放在卖出键上那一刻**有人跟我说"你上次这么扛，又多亏了 6 个点"。
改：把指标翻译成可触发的规则卡（"浮亏 >10% 且持有 >5 天时提醒"）+ 推送。做不到实时就做"上周你差点又犯的 3 个错"。

### I-B6 位置：第 58 行场景「对关键回合写交易日志」、第 161 行「日志收集：会话/消息/工具调用入参耗时全量落库」
**我的交易日志在你的产品里连个实体都不是。** 第 161 行收的是工具调用耗时——那是运维日志。我的"买入理由/计划/情绪/事后对照"**没有字段、没有表、没有界面、没有对照流程**。而且只写不用，三个月后没人点醒我。
改：日志做成一等实体，闭环三步——买之前 30 秒一句话"我为什么买"→ 卖后自动弹"这理由还成立吗"→ 季度出"我说的 vs 实际发生的"。付费价值比十个诊断指标都高。

### I-B7 位置：第 123 行「对账 FAIL 不阻断入库，但结果可被复盘系统查询」
对账对我只有一个意义：**这数我能不能信**。FAIL 不阻断、还只在 API 里可查，等于我拿着一份错数据还不知道它错，比不对账更危险。
改：FAIL 阻断该区间指标，并在我看得见的地方红字说：「3 月 12 日前后余额对不上，疑似漏一笔转账，本月收益暂不可信。[看断点行]」。工程师的严谨别藏在 API 响应里。

### I-B8 位置：第 109 行「无批次表」、NFR-1 仅本地归档、NFR-3 软删保历史
**两件事同时踩中我：** ①没有批次表，我想"把上次导的那份撤了重导"做不到——个人用户最需要的是后悔药，不是变更流；②**我笔记本进水了，8 年账单和历史复盘是不是就没了？** 换电脑怎么办？全篇没有备份/导出/迁移方案，而这是我敢不敢交真数据的前提。
改：加一张批次表（列表能看"10 月 15 日导入 328 行，2 行进隔离区，[撤销]"）；P0 加一键导出全量（Excel+JSON）、每周自动备份到指定目录。

某个周五晚上我想：把这个月看明白，一页纸存下来，明年翻出来看。
需要：一页 HTML/PDF/长图——"10 月交易 23 笔，赚 1200 元，跑输沪深300 2 个点；亏最多的 3 笔都是追高买入；我第 4 次在下跌里摊平；下月只做一件事：不买当日涨幅榜前 50 的票。"
现状：它只在第 60 行场景图出现**一次**，**没有任何 FR 条目**定义它。而它是用户唯一能感知的交付物，其他一切都是原料。**P0，应是 M1 的验收物。**

## 5. 如果我是你，MVP 会这样排

1. **一个本地网页不是一组 API**：双击启动，`127.0.0.1:8080` 打开就是页面，SQLite 单文件，不装 PostgreSQL。
2. **三段式导入向导**：选文件 → 自动识别+让我点两下对字段 → 结果页"导入 328 行，成功 325，3 行没看懂，点这看"，错了能撤销。
3. **首页 5 张卡片**：①分段净值 vs 沪深300（绝对收益排第一）②胜率/盈亏比/持仓天数/集中度 ③手续费合计及占比 ④处置效应 ⑤最亏 3 笔/最赚 3 笔（点开看流水）。
4. **一个"本月复盘"按钮**：一键生成一页纸，导出 PDF/长图，可微信推送。**报告是产品，指标只是原料。**
5. **一个只能点不能打字的问题列表**：10 个固定提问，背后走你那套取数，每个回答带"看流水"。

**与现方案差异**：PRD 在为"两套服务+三种更新模式+变更流+水位线+上下文预算"服务；我在为"一个人每月看一页纸"服务。基建我只留四样：导入、对账、回合配对、净值。其余不产生任何我能感知的价值，却会让 M0/M1 变成一个我打不开的系统。

## 6. 对「MVP 四问」的大白话判断

1. **净值 vs 指数**：非常关心，看懂。"这月我跑赢上证了"——但看完大概率什么也不做，甚至想加仓。**必须补沪深300和绝对收益**，否则对新股民有害。
2. **胜率×盈亏比×持仓天数×集中度**：关心，看懂一半。盈亏比 1.2 偏低、持仓 9 天说明在做短线。但四个数字堆一起我不知道**哪个是主因**，得给我一句"你的钱亏在拿不住，不是亏在选错票"。
3. **手续费占比**：最意外，也最可能真改行为。行动明确：降频，或者找华泰把万 2.5 谈到万 1.2。这是本月就能省出真金白银的数，**"有用"程度超过其他三个之和**。
4. **处置效应**：看不懂名字，看懂内容（赚一点就跑、亏了死扛），心里一沉——然后什么也不改。四问里**最需要从"检测"变"提醒"**的一项，否则只是让我难受。

补一句：四问拼不出"**我为什么亏**"。缺归因——个股/板块/买点追高/卖点太早/手续费/情绪操作各贡献多少。没有归因，四问就只是四个数字。

## 7. 我给产品经理的一句话

**这个 PRD 让我看出你懂交易——FIFO 回合、处置效应、份额法净值，都是内行才写得出来的；但我花 199 块买的是"每月一页我看得懂的复盘"，不是"一套能 API 输出的度量基础设施"。先花两周做个能双击打开、能导入、能看一页报告的界面，再回来聊水位线和上下文预算——不然你交付的一切，都只活在你自己的 Postman 里。**
