# 星星助手 · 个人交易复盘平台 v1.0 发布说明

> **版本**：1.0 ｜ **发布日期**：2026-11-22 ｜ **入口**：xingst.site
> **一句话**：把券商对账单变成复盘洞察——导入、对账、回合、净值、归因、AI 问答，一站式完成。

---

## 写在前面

个人投资者的复盘，长期困在两件事上：**账单理不清**（各券商格式各异、字段对不上、修来修去对不平账）和**结论不敢信**（Excel 算的收益差一分钱，到底是四舍五入还是逻辑错了？）。

**星星助手**从第一行代码起就对着这两个痛点：

- **账单理不清？** 华泰/平安对账单直接导入，列映射两阶段确认、批次可撤销、断链自动补差——从"上传"到"对上账"，全程可追溯。
- **结论不敢信？** 全链路**零浮点误差**——金额、价格、数量、比率一律标度整数运算，边界才转字符串；每一分收益都能拆到回合、拆到买卖理由、拆到因子。

复盘不是记账的终点，而是下一次决策的起点。v1.0 把这条链路完整交付。

## 六大亮点

### ⭐ 一键导入，账单自己会对账

- 华泰 / 平安对账单解析，v2 **两阶段导入**：列映射（乐观锁防覆盖）→ 账单类型确认 → 提交即异步落库
- 列映射模板、券商模板锁定、管理员列规则、预设类型复制——第二次导入同一券商，几乎零配置
- 预览不落库；提交后批次可整批撤销；bag 去重 + 隔离区 + 断链补差，脏数据进隔离区而不是污染账本
- **超卖卖出人工修订**：账单缺口造成的超卖可人工补录成本，服务端注入双腿并重算，注入行带 `revision_of` 标记，绝不混入真实成交

### ⭐ 收益算得对，才敢信

- **零浮点误差架构**：全仓禁止 float，金额/价格/数量/比率走标度整数（`*_units`），对账与收益复算不会出现"假断链"
- **FIFO 回合引擎**：稳定配对、分批减仓、股息归属、送转/配股、桥接恒等式；每笔回合可下钻到逐笔买卖配对
- **回合洞察**：持有期分桶（scalp/short/position/long）、买卖后 5/10/20 日前瞻收益（真实交易日历）、抄底/止损卖飞/止盈卖飞等状态旗标——把"凭感觉"变成"有对照"
- **净值与收益**：份额法 TWR、XIRR/MWR、日资产与现金流序列，口径全部文档化并版本化（`definition_version`）

### ⭐ 18 项指标 × 五因子归因，业绩拆得开

- **三域指标引擎**：核心 10 + 探索 8 共 18 个指标（收益/风险/行为），DAG 依赖 + 口径版本断点 + 门禁状态机——**口径不达标不出数**，绝不输出"看起来很像"的数字
- **五因子归因**：选股 / 板块 / 买点 / 卖点 / 费用，`Σ因子 + 残差 = 区间损益` 恒等式闭合；残差七桶显式披露（打新收益、利息、估值差……），降级只由未归因损益超容差触发，其余一律透明
- **板块暴露**：同花顺行业（互斥、权重可加总）与概念（多归属、只看暴露不加总）分开呈现，行业主动权重对照沪深300；数据缺失显式 `null + missing[]`，不用近似值糊弄

### ⭐ 星星助手：会看懂你账单的 AI 复盘搭子

- 悬浮窗随时问："我最近持仓收益怎么样？""哪只票止损卖飞最多？"
- **10 个只读工具**直连你的资产表、流水旗标、回合与洞察——回答带数据出处，不是泛泛而谈
- 语义理解与指代消解（"它"指谁、"最近"是多久），10 轮上下文窗口 + 160K token 压缩
- 问答历史留存、工具调用与 LLM 调用**全链路可回放**——每一个结论都能回溯到它的依据

### ⭐ Dashboard 与看板，一屏看完账户

- 资产概览：持仓 / 现金 / 仓位 / 总收益 / 峰值成本 / 费用 + 板块配置
- 历史概览：平仓统计 / 盈亏占比 / 最大收益 / 最大回撤
- 月度一键编排（rounds → assets → nav → metrics），收盘后增量同步行情，盘中不拉第三方数据
- **前端零口径**：页面只渲染后端格式化的数字，前端不做任何计算——所见即审计所得

### ⭐ 隐私与隔离，写进架构而不是承诺

- PostgreSQL **RLS 双层租户隔离** + 仓储层强制 `user_id` 显式过滤；跨账号访问一律 404（连"存在"都不泄露）
- 金额与凭证不进日志；客户端 IP 只以哈希使用；管理员禁读业务明细（越权即 403）
- 邮箱验证码带 pepper 的 Argon2id、刷新令牌轮换、审计留痕（不含敏感明文）
- **你的数据你做主**：账单数据可一键重置从头再导（保留账号与偏好）；数据主权在你手里

## 部署形态

- **Docker + 宿主 Caddy** 单域名同源：SPA 静态 + `/api` 反代 + TLS（Caddy 自动签发/续期），SSE 实时事件流直通
- 云主机 PostgreSQL（三角色分离：owner 迁移 / app 运行 / backup 只读，NOBYPASSRLS）
- 生产守卫 fail-closed：弱密钥拒绝启动；`/metrics`、`/docs` 公网不可达；安全头 + CSP 全量下发
- 滚动升级 + 一键回滚（镜像 tag 版本化），备份/恢复演练手册齐备（见 [DEPLOYMENT.md](DEPLOYMENT.md)）

## 数据与隐私承诺

1. 你的账单数据只属于你：RLS + 显式租户过滤双层隔离，跨账号连"资源存在"都不泄露。
2. 金额与凭证不落日志：结构化日志脱敏，IP 只存哈希，验证码带 pepper 慢哈希。
3. AI 只读不写：星星助手的 10 个工具全部只读，不会替你改一个数字。
4. 数字诚实：算不出的显式 `null`，口径不够格的不出数，降级与例外全部响应内披露。
