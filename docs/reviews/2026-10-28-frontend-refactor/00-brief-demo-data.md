## 1. 项目与页面背景

- 产品：个人股票交易复盘系统（A 股，日频，个人深度复盘）。
- 页面：**看板 / Dashboard**（当前 `/dashboard`）。现有页面：看板、交易流水、回合、净值与收益、资产、指标、导入、导入记录、设置；占位：月报、导出、归因。
- 当前前端：React 18 + Vite + 手写 CSS（单文件 `styles.css`，404 行），无组件库、无图表库、无响应式断点、顶部导航 9 项、`max-width:1080px`、表格密集、默认 14px。
- 零口径硬约束：金额/数量/比率由后端返回**已格式化字符串**，前端不做业务数值计算。预览图只需展示，不涉及计算。
- 本次重构目标：数据展示与交互更好、PC 优先并兼容 iPad、现代化/极简、适合个人深度思考分析。

## 3. 三个方案的视觉方向（必须明显区分）

### 方案 A ·「静观 Quiet Analyst」——极简编辑风

- 浅暖纸白背景（`#faf9f7` 一类）、墨色文字、单一低饱和强调色（墨绿/靛蓝任选其一）。
- 细线分隔替代卡片阴影/边框；大量留白；字号层级强（大号 tabular 数字 + 小号眉题）。
- 左侧窄导航（图标 + 文字或纯图标、可折叠），内容区宽约 1200–1360，右侧「复盘笔记 / 洞察」栏进入页面构图。
- 图表用极细线 + 单一色面积/无渐变，克制。
- 交互隐喻：像一本可交互的复盘笔记本；支持专注模式/密度切换的视觉线索。
- 关键词：留白、衬线/无衬线混排（中文可用系统字体，数字用等宽 tabular）、低对比、呼吸感。

### 方案 B ·「夜盘 Night Desk」——深色量化终端

- 近黑背景（`#0b0e12` 一类）、细网格、等宽数字，强调色青绿/琥珀（择一）。
- 多窗格：左侧图标导航栏 + 主区 + 右侧 inspector 面板（选中持仓/回合详情）；密集表格、迷你 sparkline、状态灯（绿/黄/红）。
- 图表为主视觉：净值折线 + 回撤水下区域 + 持仓热力/权重条。
- 交互隐喻：交易终端 / 监控台；键盘优先、可快速切换标的。
- 关键词：高密度、暗色、霓虹点缀、数字优先、专业感。

### 方案 C ·「Bento 现代产品风」——明亮卡片化

- 冷白/浅灰背景、16px 圆角、柔和阴影、Bento 网格；主色可用靛蓝→青渐变（克制使用）。
- 顶部栏 + 可折叠侧栏；分段控件/胶囊 tab；主图面积渐变；KPI 卡片有趋势 mini-sparkline。
- 交互隐喻：现代 SaaS 数据产品；信息按卡片分组，视觉友好、易上手。
- 关键词：圆角、层次、柔和渐变、轻盈、产品化。

## 4. 预览图产出规范

- 每个方案出 2 张：**PC 1600×2000**（整页感）、**iPad 1024×1600**（响应式布局），PNG，背景不透明。
- HTML 自包含（内联 CSS/SVG/字体栈），不引外网资源，不使用 emoji 作为图标（用内联 SVG）。
- 中文文案；数字用 tabular-nums；金额正负色区分。
- 截图命令（macOS Chrome 已安装，必须带 `--user-data-dir`，否则失败）：

```bash
mkdir -p /tmp/dsh-shots
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --no-sandbox --disable-dev-shm-usage \
  --user-data-dir=/tmp/dsh-shots/ud \
  --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1600,2000 \
  --screenshot=/absolute/path/previews/a-quiet-analyst-pc.png \
  file:///absolute/path/mockups/a-quiet-analyst.html
```

- 若页面实际高度超过窗口，先调整 HTML 使内容在目标高度内完整呈现（或把 window-size 调高到实测高度）。
