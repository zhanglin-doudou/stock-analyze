**M-P0-5｜OLS 的 SSR/SE(α) 公式量纲错误；golden 的 β/α/t/TE/IR 五数不能同时成立**
- 问题：§5.5:296 `SSR=(Syy−Sxy²/Sxx)/n²`、`s²=SSR/(n−2)`、`SE(α)=sqrt(s²(1/n+x̄²/(Sxx/n²)))`。正确：Σ(x−x̄)²=Sxx/n、`SSR=(Syy−Sxy²/Sxx)/n`、`SE(α)²=s²(1/n+x̄²/(Sxx/n))`——文档 s² 缩小 n 倍，x̄² 项又放大 n 倍。
- 证据（独立复算）：x̄=0、n=12 时 `SE_doc/SE_correct=1/√n=0.28868`（t 虚高 √12=3.464），n=60 时 t 虚高 7.75 倍。golden 反算：α_d=−0.00078896/244=−3.233e-6；由 TE=0.02690477 得日超额 σ=1.7244e-3 ⇒ 正确 SE(α)≈2.224e-4 ⇒ t≈−0.0145，而 t=−0.0045 需 SE=7.185e-4（差 3.2×）；再由 β=1.15984016 与 IR·TE=8.133%/年（算术超额）联立，需基准日漂移 2.106e-3（年化 51.4%），与 TE=2.69%/年不相容。
- 建议修复：改正公式；golden 表附 60 日 `(r_p,r_b)` 摘要或反算链，否则 t 值不可作为金标。影响：α 显著性结论错误（t 虚高 √n 倍），直接影响"跑赢/选股能力"判定。

**M-P0-6｜`ci_sample` 缺"统计量"交接：DE/BHAR 的 bootstrap CI 引擎无法代算，且顺序敏感会破坏确定性断言**
- 问题：§4.1:195 `ci_sample` 只传样本元组，§4.2:196 却要求"框架按 `sample_policy.ci` 对 ci_sample 计算"；DE 的统计量是 `(G(L+l)−L(G+g))/((G+g)(L+l))`（§7.3.1:511），**不是均值型**。`Extensibility:111` 明确 compute 只返回 `MetricValue{value,n,decomposition?,n_pending?}`、不得返回 ci；§8.6:759 断言字段集不含统计量。
- 证据：结构上无字段承载统计量 ⇒ 引擎只能按均值对 `{0,1,2,3}` 码求均值（CI 与 value 双算、口径不一致）。另 §8.6:757 `assert_deterministic` 要求"打乱 rounds/trades 顺序结果不变"，但固定 seed 的下标序列作用于未排序 `ci_sample`，**置换样本即置换 CI**。
- 建议修复：在既有 `sample_policy` 增 `stat∈{mean, ratio_of_proportions, cluster_mean}`（不新增 MetricDef 字段）；`ci_sample` 交接前按 (stat, 值) 规范排序；明示"仅内存交接、不落库、n 上限校验"。影响：D-07 不闭环；DE/BHAR/expectancy 的 CI 只能错或在 07 内自算（违"compute 不返回 ci"）。

**M-P0-7｜`data_error>5% → unreliable` 与 fx_metrics_core 的 DE golden 互斥，且阈值分母未定义**
- 问题：§7.3.1:516 定"`data_error>5%` → unreliable"。夹具 32 行＝12 closed＋1 data_error＋3 open：按回合 1/16=**6.25%**、按 closed 1/13=7.69%、按流水 1/29=3.45%——前两者判 unreliable（按 §4.2:230 无 value），第三者判 ok。

- 建议修复：定义分母（建议 data_error 回合/全部回合）并把该夹具改为 0 data_error，或把 golden 期望改为 unreliable＋无 value。影响：core 指标 behavior.de 的主 golden 按自述规则不可产出。
